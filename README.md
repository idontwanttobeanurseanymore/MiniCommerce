# 🛒 Mini E-commerce en React

## 🚀 Descripción

**Mini E-commerce** es una aplicación web de e-commerce desarrollada en React que simula una tienda online moderna. Permite visualizar productos, añadirlos al carrito y gestionar una compra básica.

El objetivo del proyecto es practicar conceptos clave de frontend moderno como el consumo de APIs, la gestión de estado global y la construcción de interfaces responsive.

---

## 🎯 Objetivos del proyecto

- ✅ Consumir datos dinámicos desde una API REST
- ✅ Implementar una arquitectura frontend limpia y escalable
- ✅ Gestionar estado global (carrito)
- ✅ Construir una UI responsive y accesible
- Aplicar testing básico (unitario e integración)

---

## 🧱 Tecnologías utilizadas

- **React** (Vite)
- **JavaScript (ES6+)**
- **SCSS (SASS + BEM)**
- **React Router**
- **Fetch API**
- **LocalStorage**

---

## 🌐 API

Se utiliza la API pública:

👉 https://fakestoreapi.com

Permite obtener productos con información como título, precio, imagen y categoría.

---

## 🧩 Funcionalidades

### 🏠 Catálogo de productos

- Listado dinámico de productos desde API
- Navegación entre productos

### 📄 Detalle de producto

- Información completa del producto
- Botón para añadir al carrito

### 🛒 Carrito

- Añadir/eliminar productos (+ / -)
- Mostrar cantidad por producto
- Cálculo automático del total
- Persistencia en LocalStorage

### 📱 Responsive Design

- Enfoque Mobile-first
- Adaptación a distintos tamaños de pantalla
